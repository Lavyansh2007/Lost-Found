# 🔍 Lost & Found Portal

A modern **Full Stack Lost & Found Management System** that helps users report lost items, browse reports, communicate through replies, and enables administrators to manage reports efficiently.

---

## 🌐 Live Website

🚀 **Live Demo:**  
https://lost-found-ucg8.onrender.com

---

## 📌 Features

### 👤 User Features

- 📝 Report Lost Items
- 🔍 Browse all reports
- 🔎 Search by item name
- 📂 Filter reports (All / Pending / Found)
- 💬 Reply to reports
- ✅ Mark an item as Found (Email Verification)
- 📱 Fully Responsive UI

---

### 👨‍💼 Admin Features

- 🔐 Admin Login
- 📊 Dashboard Statistics
- 🗑 Delete Reports
- 📈 Monitor Pending & Found Items

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Lavyansh2007/Lost-Found.git
```

Move inside the project

```bash
cd Lost-Found
```

Install dependencies

```bash
cd backend
npm install
```

Create a `.env` file

```env
MONGODB_URI=your_mongodb_connection_string
PORT=3000
```

Run the server

```bash
npm start
```

Open

```
http://localhost:3000
```
