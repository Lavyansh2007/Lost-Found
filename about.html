About the Lost & Found Portal

This website helps people report lost items and connect with those who find them.

The Lost & Found Portal is a web-based application developed to manage and track lost items efficiently.

It allows users to report lost items, view all reported cases, and respond to them if the item has been found. Admin users are provided with additional controls to manage reports.

This project demonstrates the practical use of HTML, CSS, and JavaScript in creating an interactive and functional web application.
